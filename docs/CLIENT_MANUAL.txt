Baseball Scouting AI Editor — 간편 검수 사용설명서
버전: {{APP_VERSION}} / Windows 배포 후보판 · 검수 필수
============================================================

1. 실행
다운로드한 바깥 ZIP과 내부 프로그램 ZIP을 모두 압축 해제합니다.
BaseballScoutingAIEditor.exe를 실행합니다.
EXE만 옮기지 말고 _internal 폴더를 함께 보관하세요.
Python, pip, FFmpeg를 별도로 설치할 필요가 없습니다.
새 버전은 새 폴더에 풀고 기존 버전과 프로젝트를 보존하세요.

2. 영상과 선수 선택
경기영상 불러오기에서 이용 권한이 있는 MP4/MOV/MKV 등을 선택합니다.
여러 분할 영상의 순서는 프로젝트 메뉴의 위로/아래로에서 조정합니다.
투수 또는 타자를 선택하고 선수명을 입력합니다.
팀·등번호·리그·별칭은 프로젝트 → 선수 목록·상세 정보에서 입력할 수 있습니다.
저장한 선수 불러오기와 선수 목록 백업·복원도 같은 메뉴에 있습니다.

3. 자동 탐색
선택 선수 플레이 찾기를 누릅니다. 처음에는 프로젝트 저장 위치를 정합니다.
OCR에 이름이 없더라도 후보 탐색은 계속합니다. 미확인 결과는 그대로 표시합니다.
진행률 100%는 선수 확인이나 검수 완료를 뜻하지 않습니다.
중단 버튼을 누르면 현재 처리 단위 뒤에서 멈추고 캐시를 보존합니다.
같은 경기 재탐색과 다른 선수 찾기는 기존 검수를 보관합니다.
새 결과로 전환하지 않아도 고급 메뉴의 탐색 회차에서 다시 열 수 있습니다.

4. 후보 확인
기본 플레이 후보, 신원 미확정, 다른 선수 추정, 리플레이 의심을 전환해 봅니다.
타자 자동 식별이 실패하면 미확정 목록을 보여줍니다. 성공으로 확정하지 않습니다.
행을 선택하고 클립 후보 재생을 누릅니다. 일시정지와 미리보기 크게 보기를 쓸 수 있습니다.
영상 더블클릭으로 전체 화면, Esc로 돌아옵니다.
시작·종료를 고친 뒤 구간 수정을 누릅니다.

5. 승인 — 한 개와 여러 개 모두 같은 방식
Ctrl/Shift 또는 표에서 Ctrl+A로 필요한 행을 선택합니다.
선택 클립 승인을 누르고 표시된 대상 선수·클립 수를 확인해 승인합니다.
선수 직접 확인과 클립 승인이 한 번의 작업으로 기록됩니다.
별도 선수 확인 버튼이나 체크박스를 먼저 누를 필요가 없습니다.
자동 식별이 미확정이어도 실제 영상을 확인했다면 승인할 수 있습니다.
사용자 직접 확인은 자동 OCR 성공으로 바뀌지 않습니다.
승인 전 자세히를 펼치면 각 클립 상태와 함께 확인할 타석 구성을 볼 수 있습니다.
전체 승인이 끝나는 타석은 같은 검수에서 구성을 확인한 것으로 저장합니다.
틀린 타석은 승인 전에 고급 편집에서 분리·병합하세요.
투수의 투구별 출력에는 상대 타자 이름이나 타석 확정이 필요하지 않습니다.

6. 다른 선수·리플레이로 잘못 분류된 경우
이 후보들은 일반 승인으로 바로 통과하지 않습니다.
원본을 실제 확인한 뒤 프로젝트 → 고급 편집 → 선택 클립을 투구로 재분류를 사용합니다.
그다음 선택 클립 승인으로 처리합니다. 재분류와 승인 이력은 보존됩니다.
정말 불필요한 장면은 선택 클립 제외를 누릅니다. 원본 영상은 삭제하지 않습니다.
승인을 취소하려면 프로젝트 → 선택 후보 재검수를 사용한 뒤 다시 검수하세요.

7. MP4 저장
MP4 저장을 누르면 한 창에서 다음을 선택합니다.
- 승인 클립 합본 MP4
- 투구별 개별 MP4
- 타석별 개별 MP4
저장 위치와 새 폴더 이름을 입력합니다. 실제 승인된 클립 수가 표시됩니다.
기존 폴더는 덮어쓰지 않으므로 다른 이름을 사용하세요.
기본은 원본 화면비율 보존, 720급, 30fps입니다.
화면비율·화질 설정은 필요한 경우에만 고급 영역을 펼칩니다.
타석별 출력에서 아직 구성이 미확인된 경우 같은 창에서 구성 확인을 할 수 있습니다.
타석이 아예 없는 클립을 임의로 합치지는 않습니다. 고급 편집에서 구성하세요.
출력 후 생성 파일명과 저장 위치가 표시됩니다.
영상·음성·선수·후속 플레이가 제대로 포함됐는지 실제 재생 검수하세요.

8. 선수 변경과 프로젝트 저장
분석 후 현재 검수 선수는 고정됩니다. 다른 선수 찾기로 다음 검색 대상을 입력합니다.
입력 중인 다음 선수와 현재 검수·출력 선수는 혼합되지 않습니다.
프로젝트 → 프로젝트 저장을 사용합니다. 기존 저장 위치는 다시 묻지 않습니다.
다른 이름으로 저장하려면 해당 메뉴를 선택하세요.
선수 목록은 Windows 사용자 데이터 폴더에 있으므로 ZIP 업데이트만으로 지워지지 않습니다.

9. 고급 기능
프로젝트 메뉴에서 이닝·투구 번호 수정, 타석 분리·병합, 상대 타자명,
OCR 근거, 진단 CSV/JSON, 방송 프로필 보정, 탐색 회차 복원, 선수 DB 관리,
상세 화면비율 및 견제/리플레이 분류를 사용할 수 있습니다.
기본 영상 추출 작업에서 이 기능들을 모두 사용할 필요는 없습니다.

10. 현재 한계
이 프로그램은 배포 후보판입니다. 모든 경기의 모든 투구·타석을 찾는 완성판은 아닙니다.
작은 자막·다른 방송 구도에서 오독·누락·오탐이 남습니다.
유니폼 등번호 인식과 선수 연속 추적은 아직 구현되지 않았습니다.
사용자 승인은 검수 기록이며 자동 식별 성공률의 증거가 아닙니다.
전체 경기와 후속 플레이 보존은 확인한 범위에서만 판단하세요.
도움말 → 프로그램 정보·빌드 확인에서 버전·커밋·엔진을 확인할 수 있습니다.
원본, 선수 DB, 검수 프로젝트를 공개 GitHub에 올리지 마세요.
