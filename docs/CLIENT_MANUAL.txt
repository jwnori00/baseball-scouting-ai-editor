Baseball Scouting AI Editor — 클라이언트 사용설명서
대상 버전: 1.0.0.integration-preview6 (통합 검증판)
============================================================

중요: 처음 보는 모든 경기에서 모든 선수·투구·타석을 정확하게
찾는 완성판은 아닙니다. 자동 후보를 검수한 뒤 사용하세요.
진행률 100%와 Windows 실행 성공은 야구 분석 정확성 검증이 아닙니다.

preview6 타자 모드 변경 안내
------------------------------------------------------------
타자 신원 식별 완성판이 아닙니다. 유니폼 등번호 인식과 선수 추적은 미구현입니다.
타자 모드 기본 목록은 목표 선수 ID 근거가 있는 후보만 보여줍니다.
빈 목록은 전체 경기에서 그 선수가 없다는 뜻이 아닙니다.
'전체 플레이 후보'와 '타자명 일치 근거·신원 미확정' 필터를 확인하세요.
프로젝트 → 타자명 자막 근거 보기에서 관측된 OCR 이름·시각을 확인할 수 있습니다.
자막의 이름·번호 근거는 실제 선수 신원과 유니폼 번호 확인을 대신하지 않습니다.
타자명 근거가 없으면 타석을 자동 생성하지 않고 미배정으로 둡니다.
선택 투구를 한 타석으로 묶는 수동 검수 기능은 유지합니다.
구버전의 근거 없는 자동 타석을 정리하려면 작업파일을 먼저 별도로 보관하고
프로젝트 → 근거 없는 자동 타석 정리 · 검수 보관을 사용하세요.
검수 기록이 있거나 타자 정보·확정이 있는 그룹은 자동 정리하지 않습니다.
정리 후 프로젝트를 저장하세요. 회차 비교·되돌리기에서 정리 전 상태를 복원할 수 있습니다.
OCR 수행 방식이 바뀌어 구버전 캐시를 보존한 채 재분석이 필요할 수 있습니다.
자세한 검증 결과와 실패 사례는 docs/BATTER_IDENTITY_REPAIR.md에 있습니다.

1. 실행
------------------------------------------------------------
받은 ZIP을 새 폴더에 전부 압축 해제하고 EXE를 실행합니다.
안에 프로그램 ZIP이 더 있으면 그것도 압축 해제하세요.
EXE와 _internal 등 동봉 폴더를 분리하지 마세요.
Python·FFmpeg·pip를 별도로 설치하지 않습니다.

2. 기본 작업 순서
------------------------------------------------------------
경기영상 불러오기 → 분석 선수 선택 → 선수 플레이 자동 탐색
→ 플레이 검수 → 스카우팅 영상 저장

같은 경기의 분할 영상만 시간순으로 정렬하세요.
서로 다른 경기를 한 경기처럼 섞지 마세요.
원본 영상은 변경·이동하지 말고 별도로 보관하세요.
유튜브 URL 가져오기 기능은 없으며 이용 권한이 있는 로컬 파일을 사용합니다.

3. 분석 선수 선택·선수 목록
------------------------------------------------------------
투수/타자, 이름, 팀, 등번호, 리그, 경기 날짜를 입력합니다.
다른 언어 이름과 별칭은 쉼표로 구분합니다.
'선수 불러오기'로 저장된 선수 정보를 검색해 입력할 수도 있습니다.
'선수 정보 저장/수정'은 선택한 선수 기록을 저장하거나 수정합니다.
다른 사람을 별도로 등록할 때는 프로젝트 → 선수 목록 →
동명이인·별도 선수로 새 등록을 사용하세요.
이름만 같다는 이유로 같은 선수로 자동 확정하지 않습니다.

분석·프로젝트 저장 시 선수 정보를 자동 저장합니다.
선수 목록의 최근 프로젝트는 작업파일 경로이며 원본 영상 사본이 아닙니다.
프로젝트 → 선수 목록에서 최근 프로젝트 열기, 백업·복원이 가능합니다.
JSON 백업에 영상·작업파일·화면 설정이 포함되지는 않습니다.

4. 경기영상 분석 설정
------------------------------------------------------------
새 사용자는 자동 화면 판별을 시도합니다.
이전에 저장한 직접 선택 설정이 있으면 해당 설정이 복원될 수 있습니다.
프로젝트 → 경기영상 분석 설정에서 다음을 사용할 수 있습니다.

- 자동 설정으로 되돌리기
- 화면 인식 보정
- 저장된 영상 분석 설정 불러오기
- 고급 분석 설정: 기존 LMB 등 직접 선택이 필요한 경우

리그 선택은 선수 정보이며 방송 화면 배치 선택과 다릅니다.
기존 LMB에서 사용하던 설정을 임의로 다른 방식으로 바꿀 필요는 없습니다.
자동 판단이 불확실하면 화면 보정 또는 플레이 검수가 필요합니다.

화면 인식 보정:
영상을 선택하고 대표 시각(초)을 입력합니다.
설정 이름·영상 유형·OCR 언어를 고른 뒤 항목별로 영역을 드래그합니다.
예: 투수/마운드, 타자·포수/홈, 투수 이름, 타자 이름, 팀, 등번호, 이닝.
저장하면 같은 화면 구성의 다음 경기에도 불러올 수 있습니다.
화면에 없는 정보는 다른 영역으로 대신 지정하지 마세요.
문자 영역 자동 탐색은 선수 역할이나 신원을 확정하는 기능이 아닙니다.
영역 지정과 특정 선수의 연속 추적은 다릅니다.

5. 첫 탐색과 같은 작업파일 재탐색
------------------------------------------------------------
'선수 플레이 자동 탐색'을 누릅니다.
첫 탐색에서 작업파일(JSON) 저장 위치를 선택합니다.
후보는 검수 필요 상태로 표시되며 자동 승인되지 않습니다.

같은 작업파일에서 같은 버튼을 다시 눌러 재탐색할 수 있습니다.
처리 중에는 편집을 잠가 기존 검수가 덮어써지는 일을 방지합니다.
기존 검수 결과는 보관되고 새 결과는 별도 탐색 회차가 됩니다.
프로젝트 → 탐색 회차 비교·되돌리기에서 결과를 확인하세요.

- 기존 구간과 일치: 같은 구간으로 판단한 후보
- 겹침·경계 변경 검수: 기존 후보와 겹치거나 시각이 달라진 후보
- 새 플레이: 기존 결과와 겹치지 않는 후보

'새로운 플레이만 추가'는 같은 선수·역할일 때 사용할 수 있습니다.
겹치는 후보는 자동으로 덮어쓰지 않습니다.
추가 후보의 선수·경계·타석은 다시 검수하세요.

'이 회차로 전환 · 기존 검수 보관'은 선택 회차를 현재 결과로 바꿉니다.
전환 전 검수도 별도로 보관되므로 되돌릴 수 있습니다.
검수 보관 회차를 선택해 복원하면 이전 승인·수정·제외 기록을 되돌립니다.

후보 행을 더블클릭하면 비교 대상 구간을 미리 재생할 수 있습니다.
다른 선수·투수/타자 결과는 기존 결과에 섞어 추가할 수 없습니다.
입력 선수와 현재 검수 선수가 다르면 검수·출력이 차단될 수 있습니다.
이때 원하는 회차로 전환하거나 프로젝트 메뉴의
'현재 검수 선수 정보로 입력 복원'을 사용하세요.

중단·실패 시 기존 검수는 유지하고 오류 회차와 캐시를 보존합니다.
프로그램을 강제로 끄기보다 '중단' 버튼을 사용하세요.
원본이 바뀌면 기존 결과와 연결할 수 없으므로 새 작업으로 등록하세요.

6. 플레이 검수
------------------------------------------------------------
표 위의 '현재 검수 선수'를 먼저 확인합니다.
후보를 선택하고 재생해 선수, 준비 동작, 투구, 반환 송구와
수비·주루·판정 종료까지 포함됐는지 확인합니다.
시작·종료 시각을 고친 뒤 대상 선수 확인을 체크하고
'수정 저장·검수 완료'를 누릅니다. 잘못된 장면은 제외합니다.

자동 종료 시각이 실제 플레이 종료를 보장하지는 않습니다.
선수 확인 필요, 누락 의심 구간, 다른 선수·OCR 오류, 리플레이
필터도 확인하세요. 후보가 없다고 실제 투구가 없는 것은 아닙니다.
누락을 발견하면 보조 후보를 추가해 검수할 수 있습니다.

미리보기 크게 보기:
목록과 영상 사이의 경계선을 위아래로 끌어 영상 크기를 조절합니다.
영상 더블클릭 또는 “미리보기 크게 보기” 버튼으로 전체 화면을 엽니다.
Esc 키를 누르면 기존 검수 화면으로 돌아옵니다.
이 설정은 검수용 미리보기 크기이며 저장 MP4의 화질·비율은 바뀌지 않습니다.

7. 여러 플레이 검수·이닝 수정
------------------------------------------------------------
Ctrl로 여러 행을 선택하거나 Shift로 연속 구간을 선택합니다.
'선택 플레이 일괄 검수 완료'를 누르고 모든 대상과 구간을 확인했는지 답합니다.
'표 전체 선택'은 현재 필터에 표시된 행만 선택합니다.
입력칸에서 바꾼 시각은 개별 수정 저장을 먼저 해야 반영됩니다.
리플레이·다른 선수 분류나 누락 의심 구간은 그대로 일괄 승인하지 마세요.
'수정 저장·검수 완료'도 선택한 여러 행을 처리합니다.
시작·종료 시각 수정은 현재 행에만 적용하고 다른 선택 행의 구간은 유지합니다.
대상 선수 확인 체크는 선택한 행 모두에 적용되므로 실제 확인 후 사용하세요.
선택하지 않은 행은 승인하거나 수정하지 않습니다.

이닝 칸을 더블클릭하거나 '선택 플레이 이닝 수정'을 누릅니다.
9, 9초, 9회말 형식을 지원합니다. 빈칸 또는 ?는 미확정입니다.
여러 행에 같은 값을 적용할 수 있습니다. 변경 후 작업파일을 저장하세요.

투구 번호 직접 수정:
투구 번호 칸을 더블클릭하거나 현재 행을 선택한 뒤 '투구 번호 수정'을 누릅니다.
각 투구의 번호를 직접 입력합니다. 다른 행의 번호·구간·승인은 유지합니다.
여러 행을 선택했더라도 이 수정은 현재 행 하나에만 적용합니다.
중복 번호는 확인 메시지를 표시하며 자동으로 다른 행의 번호를 바꾸지 않습니다.
번호는 편집용 표기이며 실제 투구 개수나 영상 출력 순서를 바꾸지 않습니다.
재탐색에서 새 후보만 추가할 때도 기존 수정 번호를 보존합니다.
프로젝트를 저장하면 수정 번호도 보존됩니다.

8. 타석 검수
------------------------------------------------------------
투구와 타석은 다른 단위이며 한 타석에 여러 투구가 들어갑니다.
자동 타석 연결이 틀릴 수 있으므로 확인하세요.
투수 모드에서도 상대 타자의 타석 그룹을 표시하고 편집할 수 있습니다.
한 타석의 연속 투구를 선택 → '선택 투구를 한 타석으로' → 타자명 입력.
타자 칸 더블클릭 또는 '타석 타자명 수정'으로 이름을 고칩니다.
투수의 선수 정보와 상대 타자 이름은 별도로 보존됩니다.
타석 그룹 개수와 확정 개수는 편집 줄에 표시됩니다.
이는 탐색된 후보의 그룹 수이며 실제 모든 타석 수가 확인됐다는 뜻은 아닙니다.
OCR 타자명은 신원 검증 완료가 아니라 검수 근거로 사용합니다.
같은 타석이 나뉘었으면 뒤쪽 후보를 선택해 '앞 타석과 합치기'를 사용합니다.
다른 타석이 섞였으면 시작 후보에서 '선택 플레이부터 새 타석'을 사용합니다.
완료 후 '타석 구성 확인 완료'를 누릅니다.
그룹·구간·이닝을 바꾼 뒤에는 타석 확정 상태를 다시 확인하세요.
타석 중간에서 시작한 영상만으로 전체 타석을 복원할 수는 없습니다.

9. 출력 설정 — 화면비율과 해상도
------------------------------------------------------------
'출력 설정'에서 화면비율·해상도·여백 제거를 정합니다.

화면비율:
- 원본 표시 비율 유지: 새 작업의 기본값
- 16:9, 4:3, 9:16(스마트폰 세로), 1:1
- 사용자 지정: 가로 비와 세로 비를 입력 (예: 19.5와 9)

해상도:
기본 720급, 30fps입니다. 1080급도 선택할 수 있습니다.
짧은 변을 기준으로 계산하고 긴 변은 최대 3840픽셀로 제한합니다.
720급 예: 16:9는 1280×720, 4:3은 960×720,
9:16은 720×1280, 1:1은 720×720입니다.
인코더 제약 때문에 짝수 픽셀로 반올림될 수 있습니다.
지나치게 좁은 비율은 거부합니다. 실제 예상 출력 크기를 확인하세요.

화면 배치:
전체 화면을 보존하고 비율이 다르면 여백으로 맞춥니다.
가로·세로 강제 늘리기와 화면 채우기용 자동 잘라내기는 제공하지 않습니다.
'검은 여백 제거·확대'는 별도 옵션이며 원본 구도가 달라질 수 있습니다.
원본 비율 유지와 원본 구도 유지는 같은 뜻이 아닙니다.
원본 구도를 보존하려면 여백 제거·확대를 끄세요.
확대가 손실된 원본 화질을 복원하지는 않습니다.

통합 파일은 첫 플레이 원본의 비율을 기준으로 통일합니다.
투구별·타석별 출력은 각 파일의 첫 원본을 기준으로 합니다.
다른 비율의 장면은 늘리거나 자르지 않고 여백으로 배치합니다.

설정은 작업파일에 저장됩니다. 설정 반영 후 프로젝트를 저장하세요.
이전 버전 작업파일은 기존 16:9·여백 자동 제거 설정을 유지합니다.
바꾸려면 출력 설정에서 직접 변경하세요.

10. 스카우팅 영상 저장
------------------------------------------------------------
검수 완료된 플레이를 대상으로 다음 중 하나를 선택합니다.
- 스카우팅 영상 — 통합
- 투구별 영상
- 타석별 영상

타석별 출력은 모든 출력 대상의 타석 구성을 먼저 확정해야 합니다.
'스카우팅 영상 저장'을 누르면 출력 설정과 예상 크기를 먼저 확인합니다.
설정을 확인하고 상위 폴더와 새 출력 폴더 이름을 정합니다.
기존 폴더를 덮어쓰지 않습니다. 겹치는 구간·미확인 선수는 먼저 검수하세요.
기본 출력은 H.264/AAC이며 원본 영상은 수정하지 않습니다.
완성 MP4를 별도 플레이어로 재생해 순서·누락·잘림·비율·음성을 확인하세요.
프로그램의 파일 검사는 실제 야구 장면의 정확성까지 대신 보장하지 않습니다.

11. 저장·업데이트·문제 전달
------------------------------------------------------------
검수 후 프로젝트 → 프로젝트 저장을 사용하세요.
프로젝트 파일에 원본 영상 자체가 포함되지는 않습니다.

선수 정보·영상 분석 설정은 다음 사용자 폴더에 보관됩니다.
%LOCALAPPDATA%\BaseballScoutingAIEditor
ZIP 업데이트 시 새 폴더에 압축 해제하세요. 사용자 데이터 폴더는 지우지 마세요.
선수 JSON 백업 외에 원본·작업파일·사용자 설정 폴더도 따로 백업하세요.

AV1 호환성은 동봉 디코더와 합성 8/10비트 자료로 검사합니다.
특정 사용자의 장시간 AV1 원본 전체를 검증했다는 뜻은 아닙니다.
코덱·손상 파일 오류는 파일명 변경이나 리그 변경으로 해결되지 않습니다.

오류 화면·버전·선택 선수·분석 설정·문제 영상 시각을 비공개로 전달하세요.
프로젝트 → 탐색 결과 CSV·JSON 저장으로 진단 자료를 저장할 수 있습니다.
경로·선수 정보가 포함될 수 있으니 원본과 함께 공개 GitHub에 올리지 마세요.

12. 현재 한계
------------------------------------------------------------
일부 새 중계에서 투구 누락·오탐, 선수 이름 미확인, 타석 연결 오류,
리플레이 혼동과 후속 플레이 절단이 남습니다. 모든 후보를 검수하세요.
LMP·LIDOM·LVBP·LBPRC 전체의 성능은 검증되지 않았습니다.
개인 고정·휴대전화 이동 촬영의 자동 탐색과 특정 선수 연속 추적도
지원 검증이 끝난 기능으로 안내하지 않습니다.
스마트폰 비율 입출력 지원은 이동 촬영의 탐색 정확성과 별개입니다.
수비만을 독립적으로 찾는 기능이나 유튜브 URL 가져오기는 없습니다.

이 프로그램은 후보 탐색과 검수·편집을 돕는 통합 검증판입니다.
검수하지 않은 결과를 납품용으로 사용하지 마세요.
