# 타자 자막 식별 보완 — integration-preview8

## 실제 구현

성공한 preview7 코드를 새 feat/batter-scorebug-identity 브랜치에서 재사용한다.
스코어보드 패널의 팀 색상·아이콘으로 문자 패널 채움 비율이 낮아져 전체가
탈락하는 문제를 수정했다. 화면에서 얻은 패널에 한국어/혼합어 OCR 관측을
별도로 보관한다. 파일명, 영상 시각, 선수별 시간표, 샘플 개수는 탐색 규칙에 없다.

명시적인 타자/수비 위치 표기 외에, 같은 패널에서 읽힌 볼카운트와 P 투수 행,
그 아래의 이름·타격 기록을 현재 타자 행 근거로 사용한다. 이 보조 경로는
6초 이내 서로 다른 시각에서 정확한 같은 이름이 두 번 관측돼야 확인한다.
움직임 프레임을 OCR 관측 횟수로 세지 않는다. 다른 이름·빈 이름·장면 전환·
리플레이·팀/등번호 충돌에서 이전 확인을 끊는다. 이름을 유사하게 읽었다는
이유로 요청 선수명에 강제 치환하지 않는다.

사용자가 현재 타자명 영역을 지정한 프로필도 같은 이름의 두 번 관측으로
식별할 수 있다. 입력한 팀이나 등번호를 관측된 정보처럼 사용하지 않는다.
이름이 불명확한 후보는 검수 대상으로 보존한다. 일괄 승인과 선수 확인은 분리한다.
한 패널의 카운트 관측이 서로 다르면 카운트를 자동 확정하지 않는다.

## 실제 영상 개발 검사 (독립 성능 평가 아님)

이전에 제공된 KBO 두산–LG SPOTV 및 삼성–KT MBC/SBS 계열 자막 예제 8개에
각 화면의 타자명으로 질의했다. 대상 신원 근거가 연결된 클립은 다음과 같다.

| 타자 자막 | 후보 수 | 대상 근거 연결 후보 | 결과 |
| --- | ---: | ---: | --- |
| 정수빈 | 1 | 1 | 연결 |
| 전병우 | 2 | 1 | 나머지 후보 미확정 |
| 이재현 | 3 | 0 | 자막 이름 읽기 실패 |
| 강민호 | 2 | 1 | 나머지 후보 미확정 |
| 김지찬 첫 예제 | 1 | 0 | 타자 역할 반복 근거 부족 |
| 김지찬 다른 예제 | 1 | 1 | 연결 |
| 김영웅 | 1 | 1 | 연결 |
| 구자욱 | 1 | 0 | 이름 오독, 강제 일치하지 않음 |

이는 8개 중 5개 클립에 근거가 연결됐다는 진단이다. 정밀도/재현율 62.5%라는
뜻이 아니며, 전체 투구 수와 타석 구성을 검증한 결과도 아니다. 이 자료는
수정에 사용했으므로 독립 시험 영상이 아니다. 다른 이름을 넣은 교차 질의
48개에서는 대상 확정이 없었다. 다른 영상 전체에서 오탐이 없다는 증거는 아니다.

정수빈 짧은 예제를 자동 신원 상태 그대로 검수 API/MP4 출력에 연결해
1280×720, 30fps, H.264/AAC 진단 MP4를 만들고 전체 디코딩을 확인했다.
영상은 약 8.02초이며 원본이 수비 중 끝나므로 완전한 타석·납품 영상이 아니다.
원본·프레임·사용자 DB·진단 MP4는 공개 저장소에 올리지 않는다.

## 유니폼·등번호 경로 조사

EasyOCR 1.7.2 공식 한국어 모델을 로컬에서 실제 비교했으나 작은 자막에서
이름 오독이 남아 이번 배포 의존성/모델로 채택하지 않았다. 추가 모델 학습은 없다.
공식 YOLOX Nano COCO ONNX 모델로 사람·배트 검출도 실제 시험했다.
타자 외에 포수·심판·주자 등이 함께 검출됐고 배트가 안정적으로 잡히지 않아
선수 역할/등번호 신원 판정에 사용하지 않는다. 이 모델도 배포에 포함하지 않는다.
단순 사람 검출이나 유니폼 색상을 타자 식별 완료라고 표현하지 않는다.

유니폼 등번호/이름을 역할과 연결하는 검출·추적·재식별은 미구현이다.
앞쪽 주자의 등번호를 타자의 등번호로 오인하는 문제를 피해야 한다.
읽을 수 없는 자막, 가려진 등번호, 장시간 전체 경기의 누락·오탐·타석 경계,
후속 플레이 종료, 개발에 사용하지 않은 경기의 성능은 아직 검증이 필요하다.
타자 자동 식별 완성판이 아니라 실제 자막 식별 경로를 보완한 검증판이다.

로컬 회귀 검사: 전체 121개 통과(55.11초), 최종 신원 충돌 보완 후 관련 28개 통과.
Windows 결과는 해당 커밋의 Actions 산출물로 별도 확인한다.
