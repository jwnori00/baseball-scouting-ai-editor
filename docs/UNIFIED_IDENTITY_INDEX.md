# 통합 탐색·타자 식별 검증 기록

## 구현 범위 (integration-preview7)

투구 후보 생성과 대상 선수 식별을 분리한다. 신원 상태는 TARGET_CONFIRMED,
OTHER_PLAYER, IDENTITY_UNKNOWN이며 검수 승인 및 리플레이 의심 상태와 별도로 저장한다.
전체 선택 후 일괄 승인만으로 미확인 후보를 대상 선수로 바꾸지 않는다.
사용자가 직접 본 후보는 '선택 후보 선수 확인'에서 개별 체크한 뒤 승인할 수 있다.
구버전 승인은 삭제하지 않지만, 근거 없는 기존 승인에는 신원 재확인 안내를 붙인다.

공통 SQLite 경기 인덱스는 원본 순서·해시·분석 설정으로 구분하며,
선수별 판정은 별도 쿼리로 보관한다. 같은 설정의 원시 OCR 캐시를 재사용한다.
선수명 없는 투구마다 새 타석을 만들지 않는다. 미확정 구간은 그룹 미지정으로 남긴다.

전체 화면과 영상에서 추출한 문자 패널에 Tesseract OCR을 적용한다.
현재 타자 역할 표시와 이름이 함께 읽힌 경우 그 근거를 기록한다.
같은 문자 위치에서 같은 이름이 연속 관측되는 동안만 역할 근거를 이어간다.
장면 전환·이름 소실·다른 이름·리플레이에서는 연결을 끊는다.
이는 사람 추적이나 유니폼 등번호 인식이 아니다. 입력 등번호를 영상에서 읽었다고
가정하지 않는다. 사전 점검에 신원 근거가 없으면 GUI에서 계속 여부를 묻는다.

## 실제 영상 참조 결과

새로 제공된 17개 파일 모두 전체 디코딩 통과. 내용 중복 제외 16개이며,
그중 3개는 이전 자료와 중복이다. 원본과 프레임은 비공개 로컬에만 보관한다.
모든 대표 프레임을 확인했으며 새 모델 학습은 수행하지 않았다.

16개 고유 클립의 초기 정수빈 질의에서 투구 후보 21개가 생성됐지만 전부
신원 미확정이었다. 이후 자막 위치의 연속 관측 규칙을 수정하고,
2026-10-07 19-02 (3).mp4를 재검사했다. 9 CF 정수빈 자막 근거로 후보 1개에
대상 타자 ID가 연결됐다. 이 클립은 끝 경계가 원본 종료로 잘려 검수가 필요하다.
이 결과는 전체 경기의 정수빈 타석 검증이나 유니폼 인식 성공을 의미하지 않는다.
최신 규칙으로 16개 전체의 정답 비교를 완료한 결과도 아니다.

삼성–KT 계열 자료는 같은 경기/방송 계열로 묶어 개발 참조로 취급한다.
두산–LG 정수빈 자료도 이번 수정에 사용했으므로 독립 시험 자료가 아니다.
롯데–KT, KIA–KT 자료는 참고/음성 대조 용도이며 완전한 투구 정답표가 없다.
이 자료로 정밀도·재현율이나 리그 지원 완료 수치를 산출하지 않는다.

이전 LMB Daniel 샘플의 OCR 탐색은 후보 4개 중 대상 근거 3개였다.
이전 2015 KBO 102.4초 자료는 후보 2개 모두 대상 신원을 확인하지 못했다.
박정권 2010 전체 원본과 정수빈 2015 전체 원본은 이 환경에서 접근하지 못했다.
사용자 프로젝트/SQLite의 OCR 근거 부재는 확인했지만 원본을 분석했다고 주장하지 않는다.

## 남은 장애 및 검증

유니폼 이름·등번호 검출기, 선수 재식별 및 연속 추적은 미구현이다.
작은 자막·압축 손상·옛 방송에서 OCR 실패가 남는다. 두 차례 일치한 다른 이름만
다른 선수로 판정하며 불확실한 경우 미확정을 유지한다.
실제 타석 정답, 투구 시작/종료 정답, 후속 플레이 종료 정답이 없어
타석 그룹 정확도와 누락/오탐 수치를 확정할 수 없다.
방송 구도에서 투수/타자 물리 위치를 자동 검출하는 기능도 미완료다.
자동 탐색은 검증판이며 완성된 범용 타자 식별 프로그램으로 안내하지 않는다.

Windows 빌드·합성 EXE 검사 결과는 Actions 산출물과 분리해 확인한다.
합성 검사 통과는 실제 선수 식별 성능의 증거가 아니다.

로컬 회귀 검증: Python 3.12 / Qt offscreen / Linux에서 전체 테스트 114개 통과
(55.53초). 신원 상태 보존, 미확인 후보 일괄 승인 차단, 타석·프로젝트·출력,
문자 위치 연속성 중단 및 공통 캐시 테스트를 포함한다.
이는 Windows 실제 EXE 검사 또는 실제 경기 정답 비교를 대체하지 않는다.

## 첫 preview7 Windows 실행 검사 실패와 수정

Actions 42334941256에서 Windows 테스트 114개와 PyInstaller EXE 생성은 통과했으나
EXE 검사 entry.py:129에서 실패하여 ZIP 게시가 차단됐다.
검사 타이머가 QMessageBox.done(Yes)로 대화상자만 종료해 실제 Yes 버튼이 선택되지
않았고, 승인 함수가 취소 경로로 반환했다. Linux 실제 대화상자로 동일 현상을
재현했으며 실제 Yes 버튼 click으로 변경하자 미확인 신원 거부 오류가 발생하고
기존 후보 상태가 그대로 보존됨을 확인했다. 검증 조건은 유지했다.
별도 matrix의 Windows 테스트 1개는 Tesseract 미설치로 탐색 버튼이 비활성화돼
실패했다. 테스트 머신에 OCR 도구를 설치하도록 변경했다. 사용자 PC 설치는 불필요하다.
