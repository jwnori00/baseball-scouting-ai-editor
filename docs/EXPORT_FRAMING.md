# MP4 화면 크기

MP4 저장 시 검은 여백 자동 제거·확대가 기본으로 적용됩니다.
설정은 **프로젝트 → MP4 검은 여백 자동 제거·확대**에서 해제할 수 있습니다.
전체·투구별·타석별 출력 모두 같은 설정을 사용합니다. 기존 EXE에는 적용되지 않으므로 새 ZIP을 받아 폴더 전체를 압축 해제해야 합니다.

승인된 각 구간을 순차 디코딩해 화면의 밝은 내용이 차지하는 영역의 합집합을 구합니다.
스코어보드·자막과 장면 전환을 포함하고, 안전 여유를 더한 뒤 검은 외곽을 제거합니다.
기본 출력은 1280×720, 30fps로 고정하며, 화면 비율과 음성을 보존합니다.
원본을 수정하지 않으며 적용한 크롭은 출력 폴더의 `framing.json`에 기록합니다.
모든 프레임을 메모리에 보관하지 않지만 추가 디코딩으로 저장 시간이 늘어납니다.

한 구간에 전체 화면 장면이 있거나 검은 경계가 확실하지 않으면 자르지 않습니다.
매우 어두운 내용은 경계 추정이 부정확할 수 있으므로 결과를 검수하고 필요하면 옵션을 끄세요.
작은 화면을 확대해도 원본에서 손실된 세부 화질은 복원되지 않습니다.

## 검증

제공된 비공개 5.57초 출력 샘플(1920×1080)의 검은 외곽을 자동 감지해
428×252 영역으로 자르는 것을 확인했습니다. 이후 기본 출력 규격은 1280×720, 30fps로 변경했습니다.
자동 확대 켬/끔으로 실제 기존 export 함수를 실행했으며 H.264/AAC 전체 디코딩 검사를 통과했습니다.
원본이나 추출 프레임은 저장소에 포함하지 않습니다.
합성 영상 회귀 테스트는 자동 확대·원본 구도 유지와 자막/전체 화면 전환 보존을 확인합니다.
Windows EXE 검증과 실제 경기 자동 탐색 정확도는 별도 검증 항목입니다.

## 출력 화질

H.264 CRF 18 / medium과 Lanczos 확대를 기본으로 사용해 기본 CRF 23보다 압축 손실을 줄입니다. 파일 크기와 인코딩 시간이 증가할 수 있습니다.
작은 화면으로 재저장한 파일보다 최초 경기 원본을 입력해야 원래 세부 화질을 최대한 보존할 수 있습니다. 확대는 잃어버린 디테일을 복원하지 않습니다.
