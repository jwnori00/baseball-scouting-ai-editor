# 다중 중계 학습 탐색 시험 및 검수 개선

이 빌드는 최종 실사용 정확도가 검증된 프로그램이 아닙니다.
선수 자동 식별, 실제 투구/리플레이 구별, 전체 경기 누락 검증, 플레이 종료 의미 판정은 미완료입니다.

## 실제 학습한 범위

사용자가 제공한 KBO·MLB·NPB 영상의 실제 프레임에 보조자가 시각 라벨을 붙였습니다.
25개 파일의 124개 프레임으로 NumPy 정규화 선형 구도 분류기를 학습했습니다.
입력은 공간별 밝기·채도·잔디·흙·밝은 유니폼·윤곽 특징 192개이며 CPU에서 동작합니다.
밝기 증강은 학습 프레임에만 적용했습니다. 외부 사전학습 가중치나 새 추론 라이브러리는 사용하지 않습니다.
가중치는 `profiles/camera-scene-v2.json`에 포함하며 설정의 SHA-256과 대조합니다.
시간표·선수 이름·샘플 파일명을 추론 입력으로 사용하지 않습니다.

판별하는 것은 **투구 카메라 구도**입니다. 투구 동작이나 선수 신원을 학습한 모델과 다릅니다.
기존 국소 움직임/장면 흐름 규칙과 결합해 후보를 생성합니다. 이름·팀·등번호가 확인되지 않으면 신원 미확정으로 보존합니다.
모델 점수는 보정된 확률이나 정확도가 아닙니다.

## 검증 분리와 결과

파일 SHA-256 중복과 같은 경기/녹화 계열의 학습·검증 중복을 차단합니다.
다시 첨부된 두 KBO 파일은 추가 학습 자료로 중복 사용하지 않았습니다.
학습에 넣지 않은 8개 파일의 32개 프레임을 검사했습니다.
이 중 앞선 개발 검증에 사용한 24개와 이번 추가 자료에서 분리한 8개가 포함됩니다.
라벨은 외부 독립 검수자의 확정 정답이 아니며, 프레임 수도 매우 적습니다.

| 실제 라벨 | 투구 구도로 판정 | 다른 장면으로 판정 |
|---|---:|---:|
| 투구 구도 | 10 | 2 |
| 다른 장면 | 4 | 16 |

KBO 20개 프레임 중 일치 16개, MLB 8개 중 일치 6개, NPB 4개 중 일치 4개입니다.
이는 선수별 투구 탐색 정확도·재현율이 아닙니다. 리그 전체 성능으로 해석할 수 없습니다.
인필드 전체 화면 오탐과 일부 MLB 투구 구도 누락이 남아 있습니다.
리플레이에 투구 구도가 있어도 이 모델은 실황과 자동 구별하지 못합니다.
원본 파일과 추출 프레임은 공개 저장소·Actions에 업로드하지 않습니다.

## 2015 한국시리즈 샘플

1280×720, 30fps, 영상 102.4초의 실제 디코딩을 확인했습니다.
보조자 시각 확인에서 앞부분과 약 36초 부근에 두 차례 투구가 관측됩니다.
최종 모델과 엔진의 후보는 0.1–5.2초 및 32.6–39.7초입니다.
이현승 투수 모드와 배영섭 타자 모드를 각각 실행해 동일한 두 후보를 생성했습니다.
두 모드 모두 자동 신원 확인은 0건이며, 자동 타석 연결도 확정되지 않습니다.
첫 화면의 카운트가 이미 진행 중이므로 전체 타석을 담은 샘플이 아닙니다.
사용자가 제시한 신원과 임시 시각 검수를 적용한 별도 프로젝트로 기존 MP4 출력을 검증했습니다.
이는 최종 사용자 승인이나 독립적인 경계/타석 정답 검증을 대체하지 않습니다.

## 프로그램 사용

기본값은 기존 LMB 설정을 유지합니다. KBO·MLB·NPB 예제를 시험할 때는
프로젝트 → 자동 탐색 중계 유형 → 다중 중계 학습 시험을 선택하세요.
KBO MBC 구도 규칙도 별도로 선택할 수 있습니다.
선수명 입력만으로 해당 선수의 모든 플레이를 검증해 준다고 안내하면 안 됩니다.

### 여러 후보 승인

Ctrl로 여러 행을 선택하거나 Shift로 연속 구간을 선택합니다. `표 전체 선택`도 가능합니다.
`선택 후보 일괄 승인`을 누른 뒤 선택한 모든 구간과 대상 선수를 확인했다는 질문에 답합니다.
각 후보의 기존 시작/종료 시각을 유지하고, 후보별 승인 기록을 저장합니다.
리플레이·다른 선수로 분류된 후보와 누락 의심 구간은 일괄 승인 대상이 아닙니다.
일부 후보가 실패하면 선택 전체를 변경하지 않습니다.

### 이닝 직접 수정

행을 선택하고 `선택 후보 이닝 수정`을 누르거나 이닝 칸을 더블클릭합니다.
`9`, `9초`, `9회말` 형식을 지원하며 여러 행에 한 번에 적용할 수 있습니다.
빈칸 또는 `?`는 미확정으로 되돌립니다. 후보별 이전/이후 값과 변경 기록을 보존합니다.
타석 그룹의 이닝이 섞이면 그룹 이닝은 미확정으로 표시하며 그룹을 다시 검수해야 합니다.
작업 후 프로젝트를 저장하면 재실행 후에도 유지됩니다.

## 추가 학습은 개발 환경에서 수행

사용자 Windows PC에는 Python 설치를 요구하지 않습니다.
유지보수자는 `scripts/train_camera_scene.py`에 비공개 라벨 manifest를 전달해 학습·검증합니다.
manifest 항목은 path/time/label/group/split이며, group은 프레임별이 아니라 동일 경기/녹화 계열 단위입니다.
학습 모델만 배포에 포함합니다. 실제 데이터로 투구 경계, 재현율, 선수 신원과 리플레이를 별도로 검증해야 합니다.

## 전체 예제의 엔진 진단 (실측)

2015 샘플 이외의 고유 영상 32개에 모델과 움직임 규칙을 결합해 후보 생성을 실행했습니다.
후보 수는 실제 투구 정답 수가 아닙니다. 예를 들어 `2026-11-04 20-32-44.mp4`는 2개,
`2026-11-03 22-04-58.mp4`는 4개 후보가 나왔으며 인필드·반응 장면 오탐이 남습니다.
`1000221361.mp4`는 후보 0개로 실제 투구를 놓치는 사례도 남습니다.
따라서 자동 탐색 완성판으로 표시하지 않습니다. 33개 원본은 비공개 로컬 영역에만 보관합니다.

기존 Daniel Martínez LMB 샘플에 새 모델을 적용하면 후보 7개와 후속 장면 절단이 발생했습니다.
이 때문에 기존 LMB 기본 설정을 교체하지 않았으며 해당 영상에는 기존 모드를 사용해야 합니다.
새 모델의 전체 경기/리그 일반화는 아직 미완료입니다.
