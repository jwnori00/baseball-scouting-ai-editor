# 실무용 스카우팅 영상 제작 절차

목적은 프로그램 개발이 아니라 **대상 선수의 모든 플레이를 모아 납품하는 것**입니다.
원본은 사용자 PC에 보관합니다. ChatGPT는 원본 경로만으로 영상을 볼 수 없으며,
이 문서의 프롬프트가 실제 영상 탐색 모델을 대신하지 않습니다.

## 지금 가능한 것과 필요한 것

- 다중 영상 입력·선수 지정·원본 보호·후보 저장·검수·MP4 출력 코드는 재사용합니다.
- AI 상태 분류·OCR·후보 생성은 합성 영상으로만 시험했습니다. 실제 야구 모델은 아직 없습니다.
- 개발판은 영상 처리와 검수·출력 시험용이며 자동 탐색이 비활성화됩니다.
- 실무 자동 편집의 시작 조건은 **해당 방송에서 검증한 실제 야구 자동 탐색 모델**입니다.
  이 조건이 충족되지 않으면 “자동으로 모든 투구를 찾았다”고 납품하거나,
  사용자가 경기 전체를 수동 탐색하는 방법으로 대체하지 않습니다.

## 사용할 화면과 재사용할 코드

사용자 화면은 `영상 선택 → 선수 지정 → AI 탐색 → 검수 → MP4 저장`만 중심에 둡니다.
모델 파일 경로·OCR 좌표·학습·성능 대시보드는 사용자에게 요구하지 않습니다.
분할 영상의 순서와 선수 이름/역할/팀/등번호는 작업에 필요한 입력입니다.

| 작업 | 유지하는 기존 모듈 |
|---|---|
| 단일/다중 영상, 원본 식별, 시각 연결 | ingest/media.py, core/models.py |
| 실제 영상 AI 탐색, OCR, 근거·불확실성 | vision/pipeline.py, model.py, scoreboard.py, replay.py |
| 중단·재개 | vision/cache.py |
| 후보 확인·경계 수정·승인 기록 | core/review.py, gui/window.py |
| 시간순 컷·연결·원본 오디오·MP4 검사 | export/render.py |
| ZIP 해제 후 EXE 실행 | packaging/editor.spec, Windows portable EXE workflow |

학습·평가용 기존 코드는 삭제하지 않고 개발자용으로 보존합니다. 범용 학습 기능을 추가하지 않습니다.
배포판은 PyInstaller onedir로 Python/Qt/OpenCV/NumPy/FFmpeg/OCR을 포함합니다.
최종 AI판은 검증한 모델과 중계 프로필도 포함하고 CPU로 오프라인 실행해야 합니다.
변경하지 않은 원본·비공개 자료·추출 프레임은 GitHub/CI로 보내지 않습니다.

## 반복 사용할 제작 순서

1. **의뢰 확인:** 선수 이름/별칭·팀·등번호·투수/타자·경기 날짜·원본 순서를 기록합니다.
   선수 혼동을 막을 근거와 영상 이용 권한을 확인합니다.
2. **영상 불러오기:** 한 경기의 파일을 순서대로 선택합니다. 분할 경계의 중복을 확인합니다.
3. **AI 전수 탐색:** 검증된 모델이 준비된 정식 실행 경로에서 전체 영상을 분석합니다.
   좋은 장면만 고르지 않고 볼·스트라이크·파울·아웃·안타·실점 등 모두 후보로 보존합니다.
4. **후보 검수:** AI가 찾은 후보에서 대상 선수와 시작/끝을 확인합니다.
   준비 동작부터 반환 송구까지, 인플레이는 수비·주루·판정 종료까지 보존합니다.
   리플레이/다른 선수/분할 중복은 제외하며 근거가 부족한 후보는 확정하지 않습니다.
   교체/이닝/타석 연결부와 AI 누락 경고를 우선 점검합니다.
5. **자동 출력:** 승인한 후보만 경기 시간순으로 MP4로 저장합니다.
   타자는 전체 타석 영상 또는 필요한 타석별 결과를 출력합니다.
6. **납품 확인:** 재생·소리·길이·순서·후속 플레이·누락 의심 구간을 확인합니다.
   이름·날짜가 있는 폴더에 최종 MP4와 간단한 검수 메모를 보관하고 원본은 별도 유지합니다.

실제 Daniel Martínez의 2026-08-18 경기 원본에는 접근하지 않았고 완성 MP4를 제작하지 않았습니다.
완성 영상의 수량·경계·선수 확인이 끝나기 전에는 납품 완료로 표시하지 않습니다.

## 재사용 프롬프트 1 — 의뢰 및 검수 기준

아래 프롬프트를 복사해 의뢰 내용을 정리할 때 사용합니다.
원본을 AI 서비스에 업로드하라는 의미가 아니며 필요한 정보만 제공합니다.

```text
너는 야구 스카우팅 영상 편집 검수 보조다.
목표는 하이라이트가 아니라 지정 선수의 모든 투구/타석을 시간순으로 보존하는 것이다.

선수: [이름, 별칭, 팀, 등번호]
역할: [투수/타자]
경기: [날짜, 리그, 상대팀]
원본: [파일 수와 순서, 민감한 경로 제외]
현재 자동 탐색 모델의 검증 상태: [확인한 사실만]

1. 선수 식별에 필요한 정보와 혼동 가능성을 짧게 정리하라.
2. 일반 투구는 준비 동작부터 포수 반환 송구까지, 타격/수비/주루는 실제 종료까지라는
   검수 기준을 적용하라. 볼·파울·실점·평범한 플레이도 제외하지 마라.
3. 투수 교체, 타자 교체, 이닝/타석 경계, 리플레이, 분할 중복의 확인 항목을 제시하라.
4. 실제 영상/분석 근거가 제공되지 않았으면 플레이를 봤거나 발견했다고 주장하지 마라.
5. 타임스탬프·선수·투구 수·정확도를 추측하지 마라.
6. 모델이 없으면 자동 탐색 미준비라고 표시하고 수동 전 경기 탐색으로 대체하지 마라.
```

## 재사용 프롬프트 2 — AI 후보 검수 보조

프로그램이 **실제로 생성한** 후보 목록과 근거 중 공유 가능한 부분만 사용합니다.
ChatGPT의 답은 검수 제안이며 프로그램의 승인 상태를 자동 변경하지 않습니다.

```text
다음은 로컬 영상 분석에서 나온 실제 후보 목록이다.
[후보 ID, 원본 번호, 시작/끝, 이닝, 선수 식별 근거, 종료 근거, 경고를 붙여넣기]

너는 아래 사항만 점검하라.
- 번호/시각 순서의 이상, 겹치는 구간, 중복 의심, 교체/타석 경계의 미확정 항목
- 시작 준비 동작 또는 반환 송구/후속 플레이 종료를 뒷받침하지 못하는 근거
- 이름만 있고 팀/등번호/영상 확인이 부족한 선수 식별

결과를 '후보 ID / 확인할 문제 / 원본에서 확인할 장면'으로 간결하게 작성하라.
목록에 없던 투구, 타임스탬프, 경기 결과를 만들어내지 마라.
목록의 개수만으로 전수 검출을 보증하지 마라. 사람의 영상 확인 전에는 승인하지 마라.
```

## 납품 메모 양식

```text
선수/역할:
경기/원본 수:
최종 MP4 파일:
포함한 승인 투구/타석 수:
AI 탐색 검증 상태:
사람이 확인한 내용:
방송 누락/미확정/제외 장면:
오디오·재생·시간순 출력 확인:
```
