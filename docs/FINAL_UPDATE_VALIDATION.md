기존 모델의 미사용 경기 누락·오탐·선수 미확인·타석/후속 플레이 오류는 남아 있습니다.

로컬 통합 테스트: 85개 통과, 실패·오류·건너뜀 0개 (2026-11-07 UTC).
최종 Windows 통합 빌드와 EXE 결과는 해당 실행의 build-evidence 및 portable-package.json으로 별도 확인합니다.

- 선수 목록·다국어 OCR·일괄 검수·이닝 수정·SQLite 연결 종료를 보존했습니다.

## 실제 검증과 구분

AV1 선행 Windows 빌드 42314414044는 실제 EXE의 AV1 8/10비트 디코딩과 기존 실행 검사를 통과했습니다.
이는 사용자 PC의 3시간 53분 AV1 원본 전체를 읽었다는 뜻이 아닙니다. 해당 원본은 이 환경에 제공되지 않았습니다.
최종 통합 EXE의 실제 결과는 해당 Actions 실행 및 동봉 build-evidence/portable-smoke.json을 확인해야 합니다.

Linux 검사에서는 GUI 버튼을 같은 문서에서 두 번 실행해 승인 보존과 캐시 재사용을 확인했습니다.
실제 설정/회차 대화상자 버튼, JSON 재열기, 다른 선수 혼합 방지, 실패/중단 보존을 검사했습니다.
4:3·세로·정사각형·울트라와이드·SAR·회전·혼합 비율과 VFR/AAC 타임스탬프를 합성 MP4로 시험했습니다.
파일 규격·타임스탬프 검사는 실제 장면과 소리의 의미적 동기화를 보장하는 독립 청취 검증과 다릅니다.
HDR 색/톤 매핑은 검증하지 않았습니다.

기존 실영상 분석 캐시를 재사용한 재탐색 회귀:
- Daniel Martínez LMB: 4개, 8.7–12.4 / 24.5–28.8 / 48.2–54.6 / 72.3–86.5초 유지.
- 배영섭 KBO 타자: 2개, 0.1–5.2 / 32.6–39.7초 유지. 임시 검수 승인 상태 복원 확인.
이는 새 미사용 경기 성능 측정이 아니라 기존 이미지에서 얻은 특징/원본 해시를 검증한 캐시 회귀입니다.
배영섭의 신원 확인과 동일 타석 확정은 보조자의 임시 검수이며 자동 성공으로 계산하지 않습니다.

## 학습·미사용 시험·남은 문제

이번 업데이트에서 새로운 동작/선수 모델을 학습하지 않았습니다.
기존 구도 분류기의 학습 25개 파일/124프레임, 개발 검증 8개 파일/32프레임,
이후 모델 고정 상태로 시험한 추가 8개 파일/32프레임을 그대로 유지합니다.
원본·프레임·비공개 라벨·선수 DB는 공개 저장소 및 Actions에 올리지 않았습니다.
출처와 구도 분류 결과는 INTEGRATED_STATUS.md 및 MULTI_BROADCAST_VALIDATION.md에 있습니다.
구도 분류 성능을 투구·타석·선수 식별 정확도로 표현하지 않습니다.

KBO/MLB/NPB/LMB는 제공된 일부 짧은 방송 예제만 시험했습니다.
LMP/LIDOM/LVBP/LBPRC의 확인된 독립 경기 평가, 일반 유튜브 전체,
스코어보드 없는 고정 촬영·휴대전화 이동 촬영·연속 선수 추적은 미검증/미완료입니다.
클립이 진행 중인 타석에서 시작하거나 후속 장면 전에 끝나면 없는 영상을 복원할 수 없습니다.
모든 투구·타석의 정밀도/재현율, 다른 선수 오류, 타석 합침/분리, 인플레이 절단,
검수 시간 절감을 평가할 독립 전체 경기 정답 자료가 아직 부족합니다. 해당 수치는 미측정입니다.
